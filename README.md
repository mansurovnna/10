# Читальня

Локальная система управления библиотекой. Сервер написан на Python без сторонних пакетов; данные хранятся в SQLite.

## Запуск в Windows

1. Установите Python 3.10 или новее.
2. Откройте PowerShell в папке проекта.
3. Запустите сервер:

   ```powershell
   py server.py
   ```

4. Откройте в браузере <http://127.0.0.1:8000>.
5. При первом запуске создайте логин из латинских букв, цифр, точек или знаков подчёркивания и пароль длиной не менее 10 символов.

Сервер необходимо оставить запущенным, пока используется сайт. Остановка — `Ctrl+C` в окне PowerShell.

## Данные и администрирование

- Основная база создаётся рядом с `server.py` в файле `library.db`.
- В панели администратора можно менять срок выдачи и штраф, редактировать и удалять книги и читателей, менять пароль и скачивать резервную копию SQLite.
- В карточке книги можно указать жанр и описание, а также загрузить обложку в PNG, JPG или WebP. Изображение автоматически уменьшается и хранится вместе с книгой в SQLite.
- Удаление книг и читателей, участвующих в активной выдаче, запрещено до возврата книги.
- Данные переживают перезапуск сервера и браузера. Пароль хранится как хеш PBKDF2; сессия администратора защищена `HttpOnly` cookie.
- По умолчанию сервер доступен только на этом компьютере (`127.0.0.1`); в интернет его не публикуют.

## Проверки

Запустить автоматические тесты API и базы:

```powershell
py -m unittest -v test_server.py
```
